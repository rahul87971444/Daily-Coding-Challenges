# 75. Sort Colors (Sort 0s, 1s and 2s (Dutch National Flag))

## Problem Statement

Given an array `nums` containing only `0`s, `1`s, and `2`s, sort the array in-place in ascending order.

You must solve the problem without using any built-in sorting algorithm.

---

## Example 1

### Input

```text
nums = [0,2,1,2,0,1]
```

### Output

```text
[0,0,1,1,2,2]
```

### Explanation

After sorting:

```text
0s come first,
followed by 1s,
followed by 2s.
```

Result:

```text
[0,0,1,1,2,2]
```

---

## Example 2

### Input

```text
nums = [2,0,2,1,1,0]
```

### Output

```text
[0,0,1,1,2,2]
```

---

## Example 3

### Input

```text
nums = [1,0,2]
```

### Output
